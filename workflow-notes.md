## How the GitHub Workflow Connects

The **issue** defines the work that needs to be completed. The **branch** provides a separate place to make the changes without directly changing the default branch. The **commits** record the changes made on the feature branch. The **review** provides an opportunity to check the work and identify strengths or improvements. Finally, the **pull request** brings the completed changes from the feature branch to the default branch for review and merging.
